# Assignment 7: AI Music Generation Systems Comparison

**Due:** End of Week 7
**Points:** 40

## Task

Compare 3 different AI music generation systems using the same musical prompt, and write a critical evaluation.

## Choose 3 Systems

Select from:
- **YuE** (open-source, lyrics-to-song)
- **MusicGen** (open-source, text-to-music, from Week 6)
- **Suno** (commercial, suno.com — free tier available)
- **Udio** (commercial, udio.com — free tier available)
- **Claude/GPT + SuperCollider** (LLM code generation)
- **Strudel + LLM** (browser-based live coding)

## Requirements

1. **Same prompt across all 3 systems:** Use the same musical description/lyrics for each system (adapt format as needed — e.g., lyrics for YuE/Suno, text description for MusicGen, code prompt for LLM+SC)

2. **Generate at least 1 piece per system** (2+ if using the free tools)

3. **Evaluate each system** on these criteria (rate 1-5):
   - Audio quality / production value
   - Musical coherence (melody, harmony, rhythm)
   - Style accuracy (does it match the prompt?)
   - Creative control (can you guide the output?)
   - Ease of use

4. **Create a comparison table** summarizing your ratings

## Deliverables

- Audio outputs from all 3 systems (.wav or .mp3)
- Comparison table (in your written evaluation)
- Written evaluation (500 words):
  - Which system produces the "best" music? By what criteria?
  - Which gives the most creative control to the user?
  - What are the trade-offs between open-source and commercial tools?
  - What role does the human play in each system (composer, prompter, curator)?
  - Which would you use for your own creative work, and why?
